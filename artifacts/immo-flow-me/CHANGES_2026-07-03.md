```sh
npm ci
```

Hinweis zu `npm test`: Die Heizkosten-Tests erwarten kaufmännische Rundung.
Sollte ein Test auf den ALTEN Float-Bug geeicht sein (z. B. exakt 1.00 bei
1.005), ist der Test anzupassen, nicht der Code — das neue Verhalten ist das
gesetzlich korrekte.
